# 小游戏开发环境（脚手架，玩法未定）

> ⚠️ **这里不含任何玩法**。只提供「写代码 → 打包 → 单测 → 静态检查 → 部署」这条流水线。
> 具体做什么游戏、怎么玩，由项目所有者决定；本文件只描述环境怎么用。

---

## 1. 目录结构

```
minigames/template/
├── config.json          部署与产物配置（★ levelId 必须填；output = 产物文件名）
├── game.lua             单文件产物（bundle 生成，禁止手改）
├── .luarc.json          Lua 5.3 + 运行时全局名（LuaLS 用）
├── src/
│   └── constants.lua    纯逻辑层（**不得调用 game.***，可脱离千星奇域单测）
├── platform/
│   └── game.lua         平台层骨架：OnInit / OnStart / OnLevelUpdate / OnDestroy
├── tests/
│   └── test_smoke.lua   冒烟：确认 src 模块可加载
└── tools/
    ├── bundle.ps1 | .cmd   打包 → config.json 的 output
    ├── test.cmd            打包 + 跑 tests/*
    ├── check.cmd           luac -p + LuaLS（只查 src/platform/tests）
    └── deploy.cmd          复制到映射目录 + 校验 MD5
```

**分层原则**（与主工程一致）：

| 层 | 允许 | 禁止 |
| --- | --- | --- |
| `src/*.lua` | 纯 Lua 数据结构与算法 | `game.*` / `Enum` / 任何运行时 API |
| `platform/game.lua` | 控件、输入、渲染、主循环 | 把可测的规则写进这里 |

---

## 2. config.json

```json
{
  "levelId": "",
  "output": "game.lua"
}
```

| 字段 | 含义 |
| --- | --- |
| `levelId` | 目标关卡 ID（映射目录 `...\Beyond_Local_Save_Level\<ID>\external_lua_file`）。**没填时 `deploy.cmd` 会列出候选并退出** |
| `output` | 打包产物文件名（部署到映射目录时同名） |

---

## 3. 命令（仓库根目录执行）

```powershell
& '.\minigames\template\tools\bundle.cmd'   # 打包
& '.\minigames\template\tools\test.cmd'     # 打包 + 单测
& '.\minigames\template\tools\check.cmd'    # luac -p + LuaLS
& '.\minigames\template\tools\deploy.cmd'   # 部署（需先填 levelId）
```

新增纯逻辑模块时改两处：
1. `tools/bundle.ps1` 顶部的 `$modules` 列表（顺序即依赖顺序）；
2. `tools/test.cmd` 里的 `for %%t in (...)` 用例清单。

## 4. 编辑器侧（一次性）

1. 新建**空关卡**（单人；不需要任何服务器节点图 / 信号 / 关卡变量）。
2. 放**一个客户端控件容器**，把部署后的 `game.lua` 挂到它的「客户端脚本」上。
3. 客户端控件模板（与主工程一致，索引别改）：

   | 控件 | 模板索引 |
   | --- | --- |
   | 图片控件（唯一图形模板） | `1073741910` |
   | 文本框 | `1073741908` |
   | 按键提示 | `1073741912` |
   | 光标检测区域 | `1073741914` |

   图片 ID：正方形 `100001` / 圆形 `100002` / 三角形 `100003` / 四角星 `100004` /
   五角星 `100005` / 同心圆 `100006` / 齿轮 `100161`。

4. 把关卡 ID 填进 `config.json` 的 `levelId` → `deploy.cmd` → 进关卡看日志。

> 控件创建四步、颜色 0~255、设计框自适应、输入事件名、触屏 —— 全部见仓库根目录 **`技术总结.md`**。

---

## 5. 编码约定

- `*.lua` / `*.md` / `*.json` = **UTF-8 无 BOM + LF**。
- `*.cmd` / `*.ps1` = **UTF-8 BOM + CRLF**（PowerShell 5 无 BOM 会把中文当 ANSI 读，直接语法错）。
- 产物「禁止手改」：改 `src/` 或 `platform/` 后重新打包。
